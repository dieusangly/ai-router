# AI Router

AI Router est un projet de service qui choisit un modèle d’intelligence artificielle autorisé pour chaque demande, contrôle sa réponse et conserve les éléments nécessaires pour expliquer le choix et mesurer le coût. Le service n’est pas encore implémenté dans ce dépôt.
